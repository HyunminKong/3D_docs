# Experiment Configurations

New paper-facing experiments must save a reproducible configuration here using the experiment ID, for example `EXP-006_atom_utility.yaml`.

Historical probes currently encode many arguments in their commands and scripts under `revisit3d/scripts/`. Their exact result paths and important parameters are recorded in `3D_docs/experiments/` and `Research/`.

Do not edit a configuration after results are reported. Create a new experiment ID or a suffixed configuration.
